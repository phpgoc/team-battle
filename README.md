# 团战管理工具

这是一个用于管理两支队伍团战赛事的网页工具。它支持赛事创建、队伍分配、队长投票、首轮 1v1、第二轮 KOF、大将战、实时比分和赛事历史。

## 适用角色

- **超级管理员**：创建账号和赛事，可以处理所有赛事操作。
- **非超级管理员账号**：账号创建后，可以被指定为某场赛事的赛事管理员，也可以被选为其他赛事的参赛选手。
- **赛事管理员**：这是赛事与账号的关联身份，负责被分配赛事的队伍、排阵、对局推进、比分录入和异常处理。
- **普通选手**：这是赛事与账号的参赛关联身份，查看赛事、为本队队长投票，并查看排阵和比赛进度。
- **访客**：无需登录即可查看正在进行的赛事和历史赛事。

## 赛事规则

一场赛事包含两支队伍，总参赛人数为 6–12 人，两队人数可以不同。

1. 创建赛事时，可以把部分选手固定到指定队伍，其余选手随机分队。
2. 队员可以投票选择本队队长，票数达到本队人数一半时自动确定；赛事管理员和超级管理员也可以直接指定或更换队长，也可以不设队长。
3. 第一轮是 1v1 抢分赛，默认抢 4 分。队长可以安排前半段出场顺序，其余对局由系统随机安排，也可以整轮随机。
4. 第二轮是 KOF，默认抢 5 分。胜者留场，有队长时由队长派人，无队长时队员可以自行报名。下一位置已有人或没有可报名选手时会显示提示。预报名只向本队和管理员显示，上一局结束后才公开下一场对阵；尚未派人时显示“待确认”。只有全队都输过且抢分目标大于队伍人数时，系统才随机复活选手。
5. 如果两队分别赢下前两轮，则进行大将战。大将战由双方各选择一名选手，胜者所在队伍赢得赛事。

创建赛事时可以设置首轮是队长手动排阵还是全随机，也可以设置随机排阵的优先规则。大将战可以分别设置“多胜选手”“多败选手”和多个特殊候选组的概率，未分配的概率由系统全随机兜底。KOF 首发默认随机，也可以在赛事设置中指定。

赛事设置还可以设置随机抽人的时长，默认随机抽人 3 秒、大将战抽人 5 秒。这两个时间由赛事管理员在比赛进行中也可以调整。赛事尚未完成选手和队伍分配时，直播地址会引导有权限的管理员进入设置页，其他人不能查看未准备好的直播页。

## 基本操作

超级管理员登录后可以创建账号和赛事，选择赛事管理员、参赛选手、队伍和抢分目标。赛事管理员进入赛事工作台后，可以确认队长、生成或调整首轮排阵、开始对局并录入胜负。

赛事进行中，任何人都可以打开公开赛事页面查看当前比分、正在进行的对局、队伍阵容和赛事进度。赛事结束后，可以在历史页面查看完整对局和操作记录。

历史赛事由超级管理员按轮次录入每一场对局，保存后与实时赛事使用相同的详情页面展示。分类图标使用上传的图片文件，账号和赛事看板会显示头像与分类图片。

在历史或实时对战页面点击选手姓名，可以通过弹出层查看其总胜负、对不同分类的胜负和大将战胜负，无需登录。登录后也可以在账号设置中打开“我的战绩”，显示内容相同。战绩包含已录入胜负的历史和进行中对局，不包含已取消赛事；分类按对手当前分类汇总。

## 启动

编译后运行程序即可启动网页服务，默认访问地址为 `http://localhost:9527`：

```text
go build -o team-battle .
./team-battle
```

程序提供三个可选启动参数：

- `--db`：SQLite 文件路径，默认是当前目录的 `team-battle.sqlite`。
- `--host`：监听地址，默认是 `localhost`。
- `--port`：监听端口，默认是 `9527`。

例如：

```text
./team-battle --db ./data/battle.sqlite --host 0.0.0.0 --port 9527
```

程序只提供 HTTP，不内置 TLS。需要 HTTPS 时，请使用 Nginx 等反向代理负责证书和 TLS 终止。

开发和演示可以使用测试服务。它会使用 `test_team-battle.sqlite`，初始化 10 个测试账号、4 个分类、3 场历史赛事和 1 场进行中赛事，然后启动服务：

```text
./team-battle test
```

也可以指定测试数据库、监听地址和端口：

```text
./team-battle test --sql ./data/test.sqlite --host 0.0.0.0 --port 9528
```

测试账号的初始密码都是 `test1234`，超级管理员是 `test-admin`。

网站设置中的分类支持上传 JPG、PNG、GIF 或 WebP 图片作为分类图标。

账号管理支持创建、修改和删除账号，超级管理员可以查看所有人的登录名，修改头像、显示名、分类、身份和密码。登录名只能由本人在账号设置中修改。修改密码需输入两次新密码，无需旧密码。

登录后会长期保持登录状态，关闭浏览器或重启服务后无需重新登录。同一账号只允许一处登录，在另一台设备或浏览器重新登录会让原来的登录失效。主动退出或清理浏览器 Cookie 后需要重新登录。

普通账号的显示名和头像分别每 7 天可修改一次，超级管理员修改资料不受此限制。已有对战成绩的账号不能删除，也不能删除自己的账号。

首次使用前先初始化超级管理员。命令会生成随机密码并在终端显示一次：

```text
./team-battle init
```

默认账号名是 `admin`。可以使用 `--user` 指定账号名，也可以指定数据库：

```text
./team-battle init --user admin-root --db ./data/battle.sqlite
```

`init` 也支持使用 `--sql` 指定数据库文件，例如 `./team-battle init --user admin-root --sql ./data/battle.sqlite`。

每次使用不同账号名都可以创建新的超级管理员；如果账号名已经存在，命令会拒绝创建，也不会覆盖原密码。
