# 团战管理工具

两队团战赛事管理：第一轮 1v1、第二轮 KOF，各赢一轮时进行大将战。支持实时观赛、历史记录和个人战绩。

## 管理比赛

- **超级管理员**：管理账号、创建赛事、录入历史，维护常用赛事名、分类图标和背景；可操作所有未结束赛事。登录名只能由本人修改，不能删除自己或已有战绩的账号。
- **赛事管理员**：创建时必选，可选择任意有效账号，包括超级管理员；负责分队、队长、排阵、录分和结束确认。
- 创建赛事填写名称、开始时间（精确到小时）和管理员，选手可稍后添加。开赛需要 6–12 人，两队人数可不同；选手可固定到 A/B 队，其余随机分队。
- 选手逐个搜索、添加，右侧选择 A 队、B 队或随机；抽签前可删除。设置页始终保留录入顺序和选择，实际分队在直播、历史页查看。
- 设置页底部固定显示“保存”和“返回比赛”，整页统一保存。分队前点击大将战设置上方的“开始抽签”，依次展示分队、随机第一轮排阵和随机 KOF 首发；奇数末位随最后一组进入 A 队。队长排阵不自动生成第一轮对阵，抽签结果刷新后仍保留。
- **分组抽签前**设置第一轮、KOF 的抢分目标和出场方式，默认分别抢 4、抢 5；KOF 首发可随机或由队长安排。**首场开赛前**设置大将战多胜、多败、特殊候选及概率，剩余概率全随机。两类抽人时长默认均为 5 秒，比赛中仍可调整。
- 点击“新增特殊对战”添加一组，左、右多选框分别选A、B队候选，每组单独设置概率。待随机分队的选手两侧都可选，抽取时只取实际本队候选；某侧未选或没有本队候选时，从本队全随机。剩余概率的“全随机”包含所有参赛选手；只抽其他人请另建“特殊对战2”选入这些人。
- 管理员点击“录入获胜”，核对弹窗中的选手和胜者后，点击确认录分；回车、空格不能确认，Esc可取消。首次录分自动开赛。下一场已有排阵就直接上移；需要随机抽人时播放转盘。KOF结束、双方各赢一轮后，核对比分再点击“抽取大将”。
- 录错胜负时，在右上角“赛事设置”的“修正结果”中查看全部已打对局，点击“改为…获胜”，再统一保存。一次修正一场，该局之后的对局会删除并按正确比分推进；例如第一轮误记为 3:2，修正为 4:1 后，误抽的第六场会删除并进入 KOF。
- 大将抽取后，可在“赛事设置”调整双方大将，使用底部保存。全部对局打完后进入“待确认结束”，管理员在“赛事设置”点击“确认赛事结束”；确认前可修正录分，确认后不可编辑。广告、赞助背景仅管理员可在赛事设置中切换，并同步给所有观众。
- 超级管理员在“赛事背景”tab 上传、改名或删除背景；已绑定赛事的背景不能删除。上传自动生成压缩缩略图，管理页只加载缩略图，赛场使用原图。
- 录入过去赛事时，先确定队伍和抢分目标：偶数人数两队相同，奇数人数 A 队多1人。再分别录入第一轮、KOF，逐局选择胜者，比分自动计算；KOF胜者留场，只选败方下一人，复活时选择实际出场者。各赢一轮才录入大将战。可从任一局重新录入，该局及后续结果会清除；核对保存后不可修改。

## 选手操作

- 无队长时，点击同队其他选手右侧操作区，选择“选为队长”；达到本队人数一半（向上取整）即当选。管理员在相同位置可直接指定或取消队长。队长确定后，其他队员使用观众视图。
- 第一轮设为队长排阵时，从赛事页进入独立排阵页，按出场顺序保存；随机排阵不显示此入口。单方提交只显示“已排阵”，双方提交后才公开对阵。管理员可在排阵页切换 A/B 队，为双方排阵。
- KOF点击选手右侧操作区：队长可安排本队选手，无队长时点击自己报名；管理员直接点击任一队的合法选手派人。可提前候选，排队提示仅本人可见；上一局结束后，败方有候选就生成下一场，没有则等待派人。已输过的选手不能报名；目标分高于人数且全队都输过一次时随机复活。至少一队可能复活两次时，可在分组前开启“KOF复活不重复”：每人复活一次再开始下一轮，默认关闭。点击姓名查看战绩。
- 账号设置可修改自己的登录名、密码、显示名、头像和分类。普通账号的非密码资料共享 7 天冷却，参加的赛事未关闭时也不能修改。超级管理员修改资料不受这两项限制，登录名仍只能本人修改。密码输入两次，无需旧密码，随时可改。登录长期有效，新设备登录会使旧登录失效。

## 观赛与历史

无需登录即可观赛。首页可按参赛选手、赛事名和比赛开始日期组合筛选，分页查看历史，也可进入实时赛事。选手录满6人后即开放观赛，分队前显示统一名单；人数不足的赛事仅超管与该赛事管理员可见。实时看板自动更新；历史和直播共用全屏页面。下方“赛事规则”始终展示三轮规则，未打大将战也显示；旧记录缺少规则时显示默认值。管理员从右上角“赛事设置”修改。点击姓名可查看团战胜负、总胜负、分类对战和大将战战绩；团战按已确认结束赛事统计，正式队员未出场也计入，账号设置中也可查看自己的战绩。支持中英韩切换并保留当前页面。

选手名单和当前选手在本场赛事中赢过一局即显示红色，未赢过显示绿色，换轮不重置。实时KOF用横线标记已输过的选手，历史不显示横线。右上角三横线菜单可调面板透明度（默认30%，当前浏览器保存）、切换语言、返回首页和登录。管理员的排阵、赛事设置与菜单同排显示。

## 编译与部署

安装 Go 后在项目目录编译：

```sh
go build -o team-battle .
./team-battle
```

Windows PowerShell：

```powershell
go build -o team-battle.exe .
.\team-battle.exe
```

### 交叉编译到 Linux

Windows PowerShell（Linux x86-64）：

```powershell
$env:CGO_ENABLED = '0'
$env:GOOS = 'linux'
$env:GOARCH = 'amd64'
go build -trimpath -o team-battle-linux-amd64 .
Remove-Item Env:CGO_ENABLED, Env:GOOS, Env:GOARCH
```

Linux/macOS：

```sh
CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build -trimpath -o team-battle-linux-amd64 .
```

ARM64 服务器将 `amd64` 改为 `arm64`。把产物复制到 Linux 后运行：

```sh
chmod +x team-battle-linux-amd64
./team-battle-linux-amd64 --host 127.0.0.1
```

默认地址为 `http://localhost:9527`。首次启动自动创建数据目录和超级管理员 `admin`，初始密码 `test1234`，请登录后修改。部署只需一个可执行文件，运行后须保留数据：头像、分类图标存于数据库，背景位于数据库同目录的 `uploads/backgrounds/`。

| 参数 | 默认值 | 用途 |
| --- | --- | --- |
| `--db` | `./runtime/team-battle.sqlite` | 数据库路径 |
| `--host` | `localhost` | 监听地址 |
| `--port` | `9527` | 监听端口 |

### Nginx 反向代理

程序提供 HTTP，HTTPS 证书由 Nginx 配置。应用监听 `127.0.0.1:9527`，在 Nginx 的站点 `server` 中添加：

```nginx
client_max_body_size 50m;

location / {
    proxy_pass http://127.0.0.1:9527;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_buffering off;
    proxy_cache off;
    proxy_read_timeout 3600s;
}
```

关闭代理缓冲以保证实时比分及时推送。运行 `nginx -t` 检查配置，再运行 `nginx -s reload` 生效。
