# 팀전 관리 도구

[简体中文](README.md) · [English](README.en.md) · **한국어**

두 팀이 맞붙는 대회를 운영할 수 있습니다. 1라운드는 1대1, 2라운드는 KOF 방식으로 진행합니다. 양 팀이 한 라운드씩 이기면 대장전으로 승부를 가립니다. 실시간 관전과 지난 대회 기록, 선수별 전적을 볼 수 있습니다.

## 대회 관리

- **최고 관리자**는 계정 관리, 대회 생성, 지난 대회 결과 입력을 담당합니다. 자주 쓰는 대회명, 분류 아이콘, 배경도 관리하며 종료 전인 모든 대회를 운영할 수 있습니다. 로그인 이름은 계정 본인만 변경할 수 있습니다. 본인 계정과 경기 전적이 있는 계정은 삭제할 수 없습니다.
- 최고 관리자는 **대회 관리**에서 모든 대회를 볼 수 있습니다. 왼쪽의 대회명을 누르면 상세 화면이 열립니다. 종료된 대회는 오른쪽에서 삭제하거나 복원할 수 있습니다. 삭제한 대회는 데이터가 보존되며, 기본적으로 홈 화면에서 숨겨지고 전적 집계에서 제외됩니다. **삭제된 대회 표시**를 선택하면 볼 수 있고, 복원하면 전적에 다시 반영됩니다.
- 대회를 만들 때 **대회 관리자**를 반드시 지정합니다. 최고 관리자를 포함한 모든 활성 계정을 선택할 수 있습니다. 대회 관리자는 팀 편성, 주장 지정, 출전 순서, 승패 기록, 종료 확정을 담당합니다.
- 대회명, 시작 시각(시 단위), 관리자를 입력합니다. 선수는 나중에 추가할 수 있습니다. 대회를 시작하려면 6~12명이 필요하며, 두 팀의 인원은 서로 달라도 됩니다. 선수를 A팀이나 B팀에 미리 배정하거나 무작위 추첨으로 배정할 수 있습니다.
- 선수를 한 명씩 검색해 추가한 뒤 오른쪽에서 A팀, B팀, 무작위를 선택합니다. 추첨 전에는 선수를 명단에서 뺄 수 있습니다. 설정에는 처음 입력한 순서와 배정 방식이 유지됩니다. 실제 팀 편성은 실시간 화면이나 지난 대회 상세 화면에서 볼 수 있습니다.
- 설정 화면 하단에 **저장**과 **경기로 돌아가기**가 고정되어 있습니다. **저장**을 누르면 화면 전체의 변경 사항이 반영됩니다. 팀 편성 전에는 대장전 설정 위의 **추첨 시작**을 누릅니다. 먼저 팀을 편성하고, 무작위로 설정한 경우 1라운드 대진과 KOF 선발을 차례로 추첨합니다. 인원이 홀수면 마지막 선수가 마지막 추첨 연출과 함께 A팀에 합류합니다. 1라운드 출전 순서를 주장이 정하는 경우에는 주장이 직접 제출합니다. 새로고침해도 추첨 결과는 유지됩니다.
- **팀 편성 추첨 전**에 1라운드와 KOF의 목표 승수와 출전 방식을 설정합니다. 기본 목표는 각각 4승과 5승입니다. KOF 선발은 무작위로 뽑거나 주장이 정할 수 있습니다. **첫 경기 시작 전**에 대장전의 최다승, 최다패, 특수 대전 후보와 확률을 설정합니다. 남은 확률은 완전 무작위 추첨에 배정됩니다. 선수 추첨은 기본 4초, 대장전 추첨은 기본 5초이며, 경기 중에도 시간을 바꿀 수 있습니다. 최고 관리자가 **웹사이트 설정**에서 기본 시간을 바꾸면 이후 생성하는 대회에 적용됩니다.
- **특수 대전 추가**를 눌러 후보 그룹을 만듭니다. 왼쪽과 오른쪽의 다중 선택 목록에서 각각 A팀과 B팀 후보를 고릅니다. 그룹마다 확률을 0%보다 크게 설정해야 하며, 최다승과 최다패는 0%로 설정할 수 있습니다. 팀 추첨 전에는 해당 팀에 미리 배정한 선수만 표시되고, 추첨 후에는 실제 편성 명단이 표시됩니다. 한쪽 후보가 비어 있으면 해당 팀 전체에서 추첨합니다. 완전 무작위 추첨에는 모든 선수가 포함됩니다. 나머지 선수만 대상으로 삼으려면 특수 대전을 하나 더 만들어 그 선수들을 선택하세요.
- **승리 기록**을 누른 뒤 대화 상자에서 선수와 승자를 확인하고 **확인**을 클릭합니다. 확인은 클릭으로 진행하며 Esc로 취소할 수 있습니다. 첫 결과를 입력하면 대회가 시작됩니다. 다음 대진이 정해져 있으면 바로 현재 경기 영역에 표시되고, 선수를 새로 뽑아야 하면 추첨 애니메이션이 재생됩니다. KOF 종료 후 양 팀이 한 라운드씩 이겼다면 점수를 확인하고 **대장 추첨**을 누릅니다.
- 승패를 잘못 입력했다면 오른쪽 위 **대회 설정**의 **결과 수정**에서 완료된 경기를 모두 확인할 수 있습니다. 올바른 승자를 선택하고 저장합니다. 한 번에 한 경기만 수정할 수 있습니다. 수정한 경기 이후의 대진과 결과는 삭제되고, 수정된 결과부터 다시 진행됩니다. 예를 들어 1라운드 점수를 3대2에서 4대1로 바로잡으면 잘못 추첨된 6번째 경기가 삭제되고 KOF로 넘어갑니다.
- 대장을 추첨한 뒤에는 **대회 설정**에서 양 팀의 대장을 변경하고 저장할 수 있습니다. 모든 경기가 끝나면 **종료 확정 대기** 상태가 됩니다. 대회 관리자는 **대회 종료 확정**을 누르기 전까지 결과를 수정할 수 있습니다. 확정하면 수정할 수 없습니다. 광고나 스폰서 배경은 관리자만 대회 설정에서 변경할 수 있으며, 변경 사항은 모든 관전자에게 반영됩니다.
- 최고 관리자는 **대회 배경**에서 이미지를 올리고, 이름을 바꾸고, 삭제할 수 있습니다. 대회에 사용 중인 배경은 삭제할 수 없습니다. 이미지를 올리면 관리 화면용 압축 썸네일이 자동으로 생성됩니다. 대회 화면에는 원본이 표시됩니다.
- 지난 대회를 입력할 때는 먼저 팀과 목표 승수를 정합니다. 인원이 짝수면 양 팀 인원이 같아야 하며, 홀수면 A팀에 한 명이 더 있어야 합니다. 1라운드와 KOF를 각각 입력합니다. 승자를 누르면 결과가 바로 기록되고 점수가 자동으로 계산됩니다. KOF에서는 승자가 남으므로 패한 팀의 다음 선수만 선택합니다. 부활한 경우 실제로 다시 출전한 선수를 고릅니다. 양 팀이 한 라운드씩 이겼다면 대장전도 입력합니다. 원하는 경기부터 다시 입력할 수 있으며, 해당 경기와 이후 결과가 지워집니다. 내용을 확인한 뒤 최종 저장하면 수정할 수 없습니다.

## 선수 조작

- 팀에 주장이 없으면 다른 팀원 이름 오른쪽의 조작 영역을 눌러 **주장으로 투표**를 선택합니다. 팀 인원의 절반(소수점 올림) 이상이 투표하면 주장으로 선출됩니다. 대회 관리자는 같은 곳에서 주장을 직접 지정하거나 해제할 수 있습니다. 주장이 정해지면 다른 팀원은 관전자 화면을 사용합니다.
- 1라운드 출전 순서를 주장이 정하는 경우 대회 화면에서 **1라운드 라인업**으로 들어가 출전 순서를 저장합니다. 무작위 편성에서는 이 메뉴가 표시되지 않습니다. 한 팀만 제출한 상태에서는 **출전 순서 제출 완료**만 표시되며, 양 팀이 모두 제출해야 대진이 공개됩니다. 대회 관리자는 라인업 화면에서 A팀과 B팀을 전환해 양쪽의 출전 순서를 정할 수 있습니다.
- KOF에서는 선수 행 오른쪽의 조작 영역을 사용합니다. 주장은 자기 팀 선수를 지명할 수 있고, 주장이 없는 팀의 선수는 자신의 행을 눌러 출전을 신청할 수 있습니다. 대회 관리자는 어느 팀이든 출전 자격이 있는 선수를 지명할 수 있습니다. 미리 신청하거나 지명할 수 있으며, 대기 상태는 해당 선수만 볼 수 있습니다. 이전 경기가 끝나면 패한 팀의 대기 선수가 다음 경기에 나오고, 대기 선수가 없으면 선수가 정해질 때까지 기다립니다. 이미 패한 선수는 신청할 수 없습니다. 목표 승수가 팀 인원보다 많고 팀원 전원이 한 번씩 패했다면 무작위로 한 명을 부활시킵니다. 한 팀이라도 부활이 두 번 이상 필요할 수 있다면 팀 추첨 전에 KOF 부활 중복 방지를 켤 수 있습니다. 이 옵션을 켜면 전원이 한 번씩 부활한 뒤 다음 부활 순환이 시작됩니다. 기본값은 꺼짐입니다. 선수 이름을 누르면 전적을 볼 수 있습니다.
- 계정 설정에서 본인의 로그인 이름, 비밀번호, 표시 이름, 아바타, 분류를 변경할 수 있습니다. 일반 계정은 비밀번호 외 항목을 하나라도 변경하면 다른 항목까지 7일 동안 변경할 수 없습니다. 참가 중인 대회가 종료되기 전에도 이 항목들은 변경할 수 없습니다. 최고 관리자는 언제든 프로필을 수정할 수 있으며, 로그인 이름은 계정 본인만 변경할 수 있습니다. 비밀번호는 언제든 바꿀 수 있습니다. 이전 비밀번호 없이 새 비밀번호를 두 번 입력하면 됩니다. 로그인은 계속 유지되며, 새 기기에서 로그인하면 이전 기기의 로그인이 해제됩니다.

## 관전과 지난 대회

로그인 없이 관전할 수 있습니다. 홈 화면에서 참가 선수, 대회명, 시작 날짜를 조합해 지난 대회를 검색하고 페이지별로 볼 수 있습니다. 진행 중인 대회도 홈 화면에서 열 수 있습니다. 선수가 6명 이상 등록되면 관전이 가능하며, 팀 편성 전에는 전체 선수 명단을 표시합니다. 인원이 부족한 대회는 최고 관리자와 해당 대회 관리자만 볼 수 있습니다. 실시간 점수판은 자동으로 갱신되고, 지난 대회와 진행 중인 대회는 같은 전체 화면을 사용합니다. 하단의 **대회 규칙**에는 대장전이 열리지 않은 경우에도 세 라운드의 규칙이 표시됩니다. 나중에 기록한 대회는 이 영역에 **사후 입력**만 표시합니다. 관리자는 오른쪽 위 **대회 설정**에서 설정을 수정할 수 있습니다. 선수 이름을 누르면 팀전 승패, 전체 승패, 상대 분류별 전적, 대장전 전적을 볼 수 있습니다. 팀전 전적은 종료가 확정된 대회를 기준으로 집계하며, 실제 경기에 나오지 않은 정식 팀원도 포함합니다. 본인의 전적은 계정 설정에서도 볼 수 있습니다. 중국어, 영어, 한국어로 전환해도 현재 화면은 유지됩니다.

선수 명단과 현재 대진에서는 해당 대회에서 한 경기라도 이긴 선수를 빨간색으로, 아직 이기지 못한 선수를 초록색으로 표시합니다. 라운드가 바뀌어도 색상은 유지됩니다. 실시간 KOF에서는 이미 패한 선수 이름에 취소선을 표시합니다. 지난 대회에서는 색상만 표시합니다. 오른쪽 위의 줄 세 개 메뉴에서 패널 투명도(기본 30%, 브라우저에 저장)를 조절하거나 언어 변경, 홈으로 이동, 로그인을 할 수 있습니다. 관리자에게는 같은 줄에 라인업과 대회 설정 버튼이 표시됩니다.

## 빌드 및 배포

Go를 설치한 뒤 프로젝트 디렉터리에서 빌드합니다.

```sh
go build -o team-battle .
./team-battle
```

Windows PowerShell에서는 다음 명령을 실행합니다.

```powershell
go build -o team-battle.exe .
.\team-battle.exe
```

### Linux용 교차 컴파일

Windows PowerShell에서 Linux x86-64용으로 빌드합니다.

```powershell
$env:CGO_ENABLED = '0'
$env:GOOS = 'linux'
$env:GOARCH = 'amd64'
go build -trimpath -o team-battle-linux-amd64 .
Remove-Item Env:CGO_ENABLED, Env:GOOS, Env:GOARCH
```

Linux나 macOS에서는 다음 명령을 실행합니다.

```sh
CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build -trimpath -o team-battle-linux-amd64 .
```

ARM64 서버용으로 빌드하려면 `amd64`를 `arm64`로 바꿉니다. 생성된 실행 파일을 Linux로 옮겨 실행합니다.

```sh
chmod +x team-battle-linux-amd64
./team-battle-linux-amd64 --host 127.0.0.1
```

기본 주소는 `http://localhost:9527`입니다. 처음 실행하면 데이터 디렉터리와 최고 관리자 계정 `admin`이 생성됩니다. 초기 비밀번호는 `test1234`이며, 로그인한 뒤 변경하세요. 배포에는 실행 파일 하나가 필요합니다. 실행 후 생성되는 데이터는 보관하세요. 아바타와 분류 아이콘은 데이터베이스에, 배경 이미지는 데이터베이스와 같은 디렉터리의 `uploads/backgrounds/`에 저장됩니다.

업그레이드하려면 먼저 프로그램을 종료하고 데이터베이스와 같은 디렉터리의 `uploads/`를 백업합니다. 실행 파일을 교체하고 프로그램을 시작합니다. 기존 데이터를 보존하면서 데이터베이스를 자동으로 업그레이드하며, 실패하면 시작을 중단합니다. 이전 버전으로 돌아갈 때는 업그레이드 전 백업도 함께 복원해야 합니다.

| 옵션 | 기본값 | 용도 |
| --- | --- | --- |
| `--db` | `./runtime/team-battle.sqlite` | 데이터베이스 경로 |
| `--host` | `localhost` | 수신 주소 |
| `--port` | `9527` | 수신 포트 |
| `--sse-max-connections` | `500` | 모든 진행 중인 대회가 공유하는 실시간 연결 상한입니다. 상한에 도달하면 관전자의 브라우저가 자동으로 다시 연결을 시도합니다. |

### Nginx 리버스 프록시

프로그램은 HTTP로 서비스합니다. HTTPS 인증서는 Nginx에 설정합니다. 프로그램을 `127.0.0.1:9527`에서 실행하고 사이트의 Nginx `server` 블록에 다음 설정을 추가합니다.

```nginx
client_max_body_size 50m;

location / {
    proxy_pass http://127.0.0.1:9527;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_buffering off;
    proxy_cache off;
    proxy_read_timeout 3600s;
}
```

실시간 점수가 즉시 전달되도록 프록시 버퍼링을 끕니다. `nginx -t`로 설정을 확인하고 `nginx -s reload`로 적용합니다.
